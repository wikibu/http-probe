# http-probe

一个轻量的 HTTP 探测脚本：按可配置的间隔和次数持续探测单个 HTTP URL，实时统计各状态码出现次数，并将所有非 200 响应（时间、状态码、响应头）记录到日志文件，便于排查服务抖动、间歇性故障等问题。

提供中英文两个版本，功能完全一致，仅输出语言不同：

| 脚本 | 输出语言 |
| --- | --- |
| `http-probe.sh` | 中文 |
| `http-probe-en.sh` | 英文 |

## 功能特性

- **可配置探测节奏**：通过 `-i` 设置请求间隔（秒），`-c` 设置探测次数；默认每秒探测一次、无限循环直到 `Ctrl+C`
- **实时状态码统计**：每次探测后输出各状态码计数与总计数，例如 `[200] 9 | [503] 1 | total: 10`
- **非 200 响应留痕**：状态码不为 200 时（包括超时/无法连接记为 `000`），二次请求获取响应头，将时间、URL、状态码、响应头打印到终端并追加写入日志文件
- **最终统计**：脚本正常结束或收到 `Ctrl+C`（SIGINT）/SIGTERM 时，输出最终统计并同步写入日志
- **兼容性好**：兼容 bash 3.2（macOS 自带版本），测试脚本在无 `timeout` 命令的环境下自动降级

## 依赖

- bash（≥ 3.2）
- curl

## 使用方法

```bash
./http-probe.sh <URL> [-i <interval>] [-c <count>]
```

### 参数说明

| 参数 | 说明 | 默认值 |
| --- | --- | --- |
| `URL` | 目标地址（必填，第一个非选项参数） | — |
| `-i interval` | 请求间隔（秒），支持小数，必须为非负数 | `1` |
| `-c count` | 探测次数，必须为非负整数；`0` 表示无限（直到 `Ctrl+C`） | `0` |
| `-h` | 打印帮助信息（退出码 0） | — |

### 示例

```bash
# 每秒探测一次，直到 Ctrl+C
./http-probe.sh https://example.com

# 每 0.5 秒探测一次，共 100 次
./http-probe.sh https://example.com -i 0.5 -c 100

# 英文版，间隔 2 秒，探测 10 次
./http-probe-en.sh https://example.com -i 2 -c 10
```

### 输出示例

每次探测后刷新一行统计：

```text
[200] 9 | total: 9
```

出现非 200 响应时额外打印（并写入日志）：

```text
=== 非200响应 ===
时间: 2026-08-16 12:00:00
URL: https://example.com
状态码: 503
响应头:
HTTP/1.1 503 Service Unavailable
...
================
```

探测结束（或按 `Ctrl+C`）时输出最终统计：

```text
=== 最终统计 ===
[200] 9 | [503] 1 | total: 10
=== 统计结束 ===
```

## 日志文件

每次运行会在当前目录自动生成日志文件 `probe-results-YYYYMMDD-HHMMSS.log`，内容包括：

- 日志文件路径头行
- 每次非 200 响应的完整记录块（时间、URL、状态码、响应头）
- 运行结束时的最终统计


测试覆盖：

5. 日志文件正确创建

## 实现说明

- 单次探测超时为 30 秒（curl `--max-time`）；连接失败或超时状态码记为 `000`
- 状态码统计使用空格分隔字符串 + `sort | uniq -c` 实现，以兼容不支持 `declare -A` 关联数组的 bash 3.2
- 非 200 时的响应头通过第二次请求（`curl -D -`）获取；正常响应只取状态码、丢弃响应体，避免无谓的带宽消耗
